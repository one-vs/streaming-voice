# 🚀 T-one Initialization Scripts

Эта папка содержит скрипты для автоматической инициализации проекта T-one на разных операционных системах.

> **📚 Полная документация**: [../docs/README.md](../docs/README.md) > **🔧 Подробная настройка GPU**: [../docs/GPU_SETUP.md](../docs/GPU_SETUP.md)

## 📁 Структура

```
init/
├── windows.bat      # Полная инициализация для Windows
├── unix.sh          # Полная инициализация для Linux/macOS
├── find_cudnn.bat   # Поиск и настройка cuDNN (Windows)
└── README.md        # Этот файл
```

## 🎯 Использование

### Автоматический вызов через Makefile (рекомендуется)

```bash
# Полная инициализация проекта
make init

# Только настройка cuDNN
make setup_cudnn
```

### Прямой вызов скриптов

**Windows:**

```bash
# Полная инициализация
init\windows.bat

# Только поиск cuDNN
init\find_cudnn.bat
```

**Linux/macOS:**

```bash
# Полная инициализация
chmod +x init/unix.sh
./init/unix.sh
```

## 🔧 Что делают скрипты

### `windows.bat` / `unix.sh`

1. ✅ Проверяет наличие `uv` (устанавливает если нужно)
2. ✅ Создает виртуальное окружение `.venv`
3. ✅ Устанавливает все зависимости Python
4. ✅ Скачивает AI модели (144MB)
5. ✅ Настраивает GPU поддержку (Windows)
6. ✅ Выводит инструкции по запуску

### `find_cudnn.bat`

1. 🔍 Ищет cuDNN в стандартных путях NVIDIA
2. 📋 Копирует `cudnn64_9.dll` в папку `libs/`
3. ⚠️ Создает заглушку если не найден
4. ✅ Настраивает PATH для проекта

## 📋 Требования

### Обязательные:

- **Git** для клонирования репозитория
- **Интернет** для скачивания зависимостей

### Автоматически устанавливается:

- **uv** (Python package manager)
- **Python зависимости** (onnxruntime-gpu, fastapi, etc.)
- **AI модели** (акустическая модель 144MB)

### Для GPU (опционально):

- **NVIDIA GPU** с CUDA 12.x
- **CUDA Toolkit** (автоматически определяется)
- **cuDNN 9.x** (автоматически ищется и копируется)

## 🚀 Следующие шаги

После инициализации:

1. **Активируйте окружение:**

   ```bash
   # Windows
   .\.venv\Scripts\Activate.ps1

   # Linux/macOS
   source .venv/bin/activate
   ```

2. **Запустите сервер:**

   ```bash
   make up_dev          # Компактный режим
   make up_dev_full     # Полный режим с KenLM
   ```

3. **Откройте браузер:**
   ```
   http://localhost:8080
   ```

## 🐛 Устранение проблем

### uv не найден

- Скрипты автоматически установят uv
- Может потребоваться перезапуск терминала

### cuDNN не найден (Windows)

- Установите NVIDIA cuDNN с официального сайта
- Или работайте без GPU: `TONE_USE_GPU=false make up_dev`

### Модели не скачиваются

- Проверьте интернет соединение
- Запустите: `make download_models`

### Права доступа (Linux/macOS)

- Сделайте скрипт исполняемым: `chmod +x init/unix.sh`
