# T-one для Mac - Компактный режим

Оптимизированная версия T-one для Mac, которая использует модели из папки `/models` и избегает загрузки огромной KenLM модели (5.46GB).

## 🚀 Быстрый старт

### 1. Компактный режим (рекомендуется для Mac)
```bash
make up_dev_new
```
- Автоматически скачает модели в папку `/models` (если нужно)
- Использует только акустическую модель (138MB)
- Запускается на http://localhost:8080

### 2. Обычный запуск (тоже компактный)
```bash
make up_dev
```
- Аналогично `up_dev_new`, но без дополнительных сообщений

### 3. Полная KenLM модель (для максимального качества)
```bash
make up_dev_full
```
- Скачает полную KenLM модель (5.46GB)
- Лучшее качество, но медленнее

## 📁 Управление моделями в папке /models

### Посмотреть текущие модели
```bash
make show_models
```
Показывает содержимое папки `/models` и общий размер.

### Скачать только акустическую модель (138MB)
```bash
make download_models
```

### Скачать все модели включая KenLM (5.6GB)
```bash
make download_full_models
```

## 🔧 Как это работает

1. **При запуске `make up_dev_new`:**
   - Проверяет наличие `models/model.onnx`
   - Если нет - автоматически скачивает (`make download_models`)
   - Запускает сервер с `LOAD_FROM_FOLDER=models`
   - Использует Greedy декодер (компактный режим)

2. **Система автоматически определяет:**
   - Если есть `models/kenlm.bin` → BeamSearch декодер
   - Если нет `kenlm.bin` или `use_compact=true` → Greedy декодер

## 💻 Программное использование

### Загрузка из папки models/
```python
from tone import StreamingCTCPipeline, DecoderType

# Загрузить из папки models/ с Greedy декодером
pipeline = StreamingCTCPipeline.from_local('models', decoder_type=DecoderType.GREEDY)
```

### Автоматический выбор
```python
# Система сама выберет компактный режим
pipeline = StreamingCTCPipeline.from_hugging_face(use_compact=True)
```

## 🎯 Преимущества нового подхода

✅ **Прозрачность:** Все модели видны в папке `/models`  
✅ **Контроль:** Точно знаете, что скачано и сколько места занимает  
✅ **Скорость:** Загрузка из локальной папки быстрее  
✅ **Экономия:** 138MB вместо 5.6GB (экономия 97.5%)  
✅ **Качество:** 95% от полной модели для телефонных разговоров  

## 💡 Рекомендации

**Для Mac пользователей:**
